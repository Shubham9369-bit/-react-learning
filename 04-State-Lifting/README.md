# State Lifting Practice

## 📚 What I Learned

- Understood the concept of **State Lifting** in React.
- Learned how to move state from a child component to a common parent component.
- Passed state and functions between components using **props**.
- Managed data flow between sibling components through the parent.
- Practiced updating parent state from child components.
- Improved understanding of React's **one-way data flow**.
- Learned when state lifting is useful and when it can make component communication easier.

## 🛠️ Concepts Used

- React Functional Components
- useState Hook
- Props
- Event Handling
- Parent-Child Communication
- Sibling Component Communication

## 🎯 Outcome

This project helped me understand how multiple components can share the same state by lifting it to their nearest common parent, making the application more organized and easier to manage.
